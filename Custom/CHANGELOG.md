## 2026-10-16：建立自用构建流程

- `main` 保持上游代码，`codex/custom` 管理自定义改动。
- 新增 `Custom/Build.ps1`：自动发现工具，编译 x64 Release 核心和匹配插件，
  运行回归测试，再生成已签名的现代界面 `.msixbundle`。
- 将构建、测试、打包、验证及安装模板从临时目录纳入版本管理。
- 自动递增包版本，记录源码来源、界面来源、测试状态和文件哈希。
- 根据编译记录和源码指纹拒绝使用过期 DLL；通过 Windows SIP 校验签名覆盖的包内容，
  并测试更新外层哈希后仍能拒绝被篡改的 Bundle。
- 本地签名密钥进入被忽略的 `.custom-local/Signing/`，密码由当前用户的 Windows DPAPI 保护；
  后续构建复用证书，分发包只含公钥。
- 补齐中文构建、安装和上游合并说明。

限制：现代 GUI、中文资源、Shell 扩展和原版命令行仍复用现有 Preview 包；
优化 Core、Codecs、ZS.Codecs 来自源码。当前机器的完整 GUI 构建工具链尚未验证可用，
不能称为完整 GUI 源码构建。已确认此前 7.0.1870.0 包注册成功且核心哈希匹配；
本次新产物尚未安装，现代 GUI 启动仍待实际确认。

## 2026-10-16：修正安装流程

- 修复 `0x80073CF3`：已安装的官方 Bundle 必须用 `.msixbundle` 更新，不能替换为单包。
- 处理 `0x80073D02`：现有包 `UpdateWhileInUse=defer`，改用延迟注册，明确区分 pending 和 Installed。
- 安装前验证哈希、身份、证书和版本；拒绝降级，失败时导出日志和部署事件。
- 不自动卸载、结束压缩任务、重启资源管理器或关机。

## 2026-10-14：ZIP 性能优化

- 符合条件的未加密 Store/Deflate ZIP 采用最多 8 个工作线程提前解码，
  保持回调和文件输出顺序；缓冲上限 512 MiB，仍受用户内存限制约束。
- 多文件压缩按平均输入大小增大输出缓冲，保留总量和内存预算限制。
- 小文件、加密、分卷、符号链接、单线程及不支持的方法保留串行路径。
- 增加 ZIP 集成、API 回调、取消和 I/O 错误回归测试。
- 本机 6.09 GiB 音视频样本：压缩耗时约降低 21%，解压约提升 3.9 倍；
  压缩仍慢于同次测试中的 Bandizip，相同参数下 ZIP 与基线逐字节一致。

条件、数据和测量局限见仓库 `Documents/ZipPerformance.md`。
